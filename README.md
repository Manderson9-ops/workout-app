# workout-app

iPhone PWA workout logger with a rule-based, explainable plan generator (body parts, tier grades, set types, time budget).

- Personal project. Workout data stays on the device (IndexedDB); nothing is uploaded.
- Stack: TypeScript, Preact, Vite, Dexie, Vitest.
- Exercise tier grades come from a separate personal YouTube notes DB and are labeled by source.

```
npm install
npm run dev
npm test
```
